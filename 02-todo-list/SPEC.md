# 할 일 목록(투두리스트) 앱 명세서

연습용으로, 할 일을 **추가 · 완료 · 삭제**하는 웹 앱을 만든다.  
사용자는 나 혼자이고, **PC 브라우저**에서만 쓴다.

---

## 1. 목적

- 할 일을 적고, 끝났는지 표시하고, 필요 없으면 지울 수 있게 한다.
- 화면(프론트엔드)이 아니라 **서버(백엔드)** 에 저장한다.
- 저장 방식만 바꿔 가며 3단계로 실습한다.

---

## 2. 사용자

| 항목 | 내용 |
|------|------|
| 누구 | 나 혼자 |
| 어디서 | PC 브라우저 |
| 로그인 | 없음 (이번에 안 만듦) |

---

## 3. 화면

화면은 한 장이다.

1. **입력 영역**
   - 할 일 입력창
   - 추가 버튼
2. **할 일 목록**
   - 각 줄에 완료 체크박스
   - 완료한 할 일은 글자에 취소선
   - 각 줄에 삭제 버튼
3. **요약**
   - 아직 안 끝난 할 일 개수 표시

문구(버튼, 안내)는 **한글**로 한다.

---

## 4. 기능

### 4.1 추가

- 입력창에 글을 쓰고 추가 버튼을 누르면 목록에 생긴다.
- 빈 칸(공백만 있는 경우 포함)이면 추가하지 않고, 화면에 안내 문구를 보여 준다.

### 4.2 완료 표시

- 체크박스를 켜면 그 할 일은 완료가 된다.
- 완료된 할 일은 취소선으로 표시한다.
- 체크박스를 끄면 다시 안 끝난 상태로 돌아간다.

### 4.3 삭제

- 삭제 버튼을 누르면 그 할 일이 목록에서 사라진다.

### 4.4 안 끝난 개수

- 아직 완료하지 않은 할 일의 개수를 화면에 보여 준다.
- 추가 · 완료 · 삭제가 일어날 때마다 숫자가 맞춰진다.

---

## 5. 저장

- 할 일 데이터는 **서버**에 둔다. 브라우저만의 임시 저장(localStorage 등)은 쓰지 않는다.
- 한 줄의 할 일이 가지는 정보는 아래만 쓴다.

| 정보 | 설명 |
|------|------|
| 식별값 | 할 일을 구분하는 번호 |
| 내용 | 입력한 글 |
| 완료 여부 | 끝났는지 / 아직인지 |

---

## 6. 이번에 안 만들 것

- 로그인 · 회원가입
- 마감일
- 카테고리
- 할 일 글 수정
- 여러 사람 공유, 모바일 전용 화면

---

## 7. 실습 단계 (저장 방식만 바뀜)

화면과 기능(추가 · 완료 · 삭제 · 빈 칸 안내 · 개수 표시)은 3단계 내내 같다.  
바뀌는 것은 **어디에 저장하느냐**이다.

### 1단계 — 서버 메모리

- 서버가 켜져 있는 동안만 기억한다.
- 서버를 끄거나 다시 켜면 목록이 비워질 수 있다.

### 2단계 — 내 컴퓨터의 데이터베이스

- Docker로 PostgreSQL을 띄운다.
- 할 일을 그 데이터베이스에 저장한다.
- 서버를 다시 켜도, Docker 속 DB가 살아 있으면 목록이 남는다.

### 3단계 — GitHub + 자동 배포 + 클라우드 DB

- 코드를 GitHub에 올린다.
- 저장소를 푸시하면 Vercel에 자동 배포된다.
- 데이터베이스는 클라우드(Neon)를 사용한다.
- 다른 PC 브라우저에서도, 배포된 주소로 같은 목록을 본다.

---

## 8. 완료의 기준 (이 명세를 다 지켰는지)

- PC 브라우저에서 할 일을 추가할 수 있다.
- 빈 칸이면 추가되지 않고 안내가 보인다.
- 체크박스로 완료/미완료를 바꿀 수 있고, 완료는 취소선으로 보인다.
- 삭제 버튼으로 할 일을 지울 수 있다.
- 안 끝난 할 일 개수가 맞게 보인다.
- 데이터는 화면이 아니라 서버 쪽에 저장된다.
- 로그인 · 마감일 · 카테고리는 없다.
